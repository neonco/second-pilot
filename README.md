# Второй пилот учителя

Мастер-класс в рамках программы повышения квалификации
«Современный урок информатики: методики, технологии и образовательные практики»
(Архангельская область, 2026). Автор: Обозненко Арсений Михайлович, Школа 1279 «Эврика».

## Смотреть

- GitHub Pages: https://neonco.github.io/second-pilot/
- GitVerse Pages: https://neonco.gitverse.site/second-pilot

## О занятии

Практический мастер-класс про работу с ИИ-агентом `opencode` и бесплатной моделью
Big Pickle. Участники выбирают сложную тему из своего курса и собирают
одностраничник-визуализатор, которым управляет ИИ-агент.

## Файлы

- `index.html` — интерактивная презентация: листание клавиатурой (←/→),
  без боковой панели с превью, во всю ширину экрана.
- `second-pilot.pptx` — исходная презентация для скачивания.

## Кнопки в презентации

- «Скопировать промпт» — кладёт промпт для агента в буфер обмена одним кликом.
- «Показать промпт» — открывает текст промпта крупно.
- «Открыть форму» — открывает Яндекс-форму участника прямо поверх презентации
  (iframe, без перехода на другой сайт).
